| 1 | **Critical** | Prototype pollution: `find` path `__proto__.x` assigns on `Object.prototype` in the control-plane process (JSON + YAML editors) | Fixed (commit below): forbidden segments rejected in parsePath + getAt/setAt + source editors, own-property descent, defineProperty writes, null-prototype containers, import error CONFIG_KEY_FORBIDDEN; `test/security.test.ts` |
| 2 | High | INI writer emits raw values → `\n` injects keys (e.g. OpenTTD `rcon_password`) | Fixed: INI edits whose value or key contains CR/LF/C0 (TAB allowed) or INI syntax are refused with a warning, for updates and inserted keys. | 3 | High | `file` parser substitutes unescaped values → line/quote injection (FiveM `server.cfg` `add_ace`) | Fixed: `file` parser resolves placeholders with quote context from the egg template — inside "…" `\` and `"` are backslash-escaped (inside '…' `\` and `'`); outside quotes values with quotes, `;` or `\` are refused; CR/LF/C0 always refused; only the longest matching prefix rewrites a line (never merged). Tests: FiveM `sv_hostname` and `set sv_licenseKey` exploits |
| 4 | High | Backtracking regexes (done strings, `regex:` rules, config conditions) + `stripAnsi` can stall the control plane | Fixed: `re2js` 2.8.6 (pure-JS RE2) for done patterns, `regex:` config conditions (Go replacement templates via `expandGoTemplate`) and Laravel `regex:` rules (PCRE → RE2); backreferences/lookarounds/atomic/possessive rejected with a clear import issue (`VARIABLE_REGEX_UNUSABLE`, `DONE_REGEX_INVALID`) and failing closed; inputs capped at 8 KiB; `stripAnsi` is a single-pass scanner. Tests: `(a+)+$` / `(a+){10,}` on 41 chars < 50 ms in all three places; stripAnsi on ESC + 8000 `;` < 5 ms |
| 5 | Med | Empty/whitespace values skip type rules unless `nullable` semantics differ from Laravel | Fixed: only `""` is empty (fails `required`; skips other rules only with `nullable`); whitespace-only fails `required` and is otherwise validated; `integer` accepts leading zeros (`007`) and refuses surrounding whitespace (stricter than PHP about spaces, as requested); `numeric` likewise; old test updated |
| 6 | Med | `int`/`bool` aliases ignored → `between` compares string length | Fixed: `int` → `integer`, `bool` → `boolean` (validation and numeric size mode; not reported as unsupported). Test: Terraria `NPCSTREAM required|int|between:0,60` rejects 999/abc, accepts 10 |
| 7 | Med | `$` in substituted values interpreted by `String.replace` | Fixed: placeholder values substituted into `regex:` replacement templates are escaped (`$` → `$$`); replacements are expanded with Go `Regexp.Expand` semantics; all `String.replace` calls use replacer functions. Tests: BungeeCord `$2` still works; user values `$1`, `$'`, `${1}`, `$$`, `$&` stay literal |
| 8 | Med | User value can switch an XML text write into an attribute write | Fixed: `[attr='…']` is recognised on the egg template before substitution and passed as `XmlEdit.attribute`; values are always written as escaped text otherwise. | 9 | Med | Unclosed `regex:` swallows every following rule | Fixed: an unclosed `regex:` no longer swallows following rules; it fails closed (every non-empty value rejected) and the import warning names the rules that would have been swallowed. Test: `regex:/unclosed|max:2|in:a,b` |
| 10 | Med | CR/LF allowed in env values/timezone/location; non-editable variables overridable in `buildEggEnvironment` | Fixed: `buildEggEnvironment(input, { adminOverride? })` refuses CR/LF/C0 (TAB allowed) in variable values, serverId, location, timezone and IP, and ignores values for non-editable variables unless `adminOverride: true`; import warning `STARTUP_VARIABLE_UNQUOTED` for user-editable variables used unquoted in `startup` (`unquotedStartupVariables`) |
| 11 | Low | `in:`/`not_in:` not parsed as CSV | Fixed: rule parameters parsed like PHP `str_getcsv` (quotes, `""` and `\"` escapes) then trimmed. Test: `in:"a,b",c` |
